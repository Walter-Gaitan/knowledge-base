# PBSN — Activity & Gradebook Settings Checklist for Blackboard (RN-BSN)

*Settings are set per program. If a course needs a different configuration within the program, it can be adjusted.*

This document covers the available settings for Blackboard activities and gradebook, with the preferred defaults selected for the **RN-BSN** program.

---

> [!IMPORTANT]
> All ATI graded activities in the gradebook must be set to **percentage at 100 points**. Only **NR425** uses a different point distribution.

> [!IMPORTANT]
> **SafeAssign** must be turned on for all assessments/tests manually in the master shell for each one — it is **not** a global feature.
