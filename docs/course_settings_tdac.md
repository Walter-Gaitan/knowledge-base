# TDAC — Activity & Gradebook Settings Checklist for Blackboard

*Settings are set per program. If a course needs a different configuration within the program, it can be adjusted.*

This document covers the available settings for Blackboard activities and gradebook, with the preferred defaults selected for the **TDAC** program.
