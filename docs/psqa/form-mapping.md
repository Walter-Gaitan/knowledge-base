# PSQA Form Mapping

**Form URL**: [PSQA Form](https://forms.office.com/Pages/ResponsePage.aspx?id=V86IrTnQd0K3uMQU89Wa74eFLpALyTFDlgcvij0s5u1UNlQ2V0lJV1MyWUZHMkREVTQ5WUtMWFlNRi4u)

## Page 1: Introduction
1. **Course code** (Text) — Enter the course ID (e.g., "TRACY").
2. **Microsoft tracking list status** (Radio) — Select "Done".

## Page 2: LTIs
3. **LTI Links** (Radio) — Select "Correct" (or "Incorrect. Documented").

## Page 3: Respondus
4. **Respondus Activation** (Radio) — Select "Done" (or "N/A").

## Page 4: TDAC Due dates
5. **Due Dates** (Radio) — Select "Done" (or "N/A").

## Page 5: Gradebook
6. **Grade Distribution** (Radio) — Select "The overall grade distribution matches the syllabus" (or "In at least one assessment...").
7. **Gradebook Sorting** (Radio) — Select "All items in the Gradebook are sorted correctly" (or "At least one item...").
8. **Grade Schema** (Radio) — Select "All the indications above are met" (or "One or more indications...").

## Page 6: Wrap-Up
9. **Time Spent** (Radio) — Select "Done".
10. **Final Status Change** (Radio) — Select "Done".
