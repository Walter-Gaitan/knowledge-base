# Activity & Gradebook Settings Checklist for Blackboard

*Settings are set per program. If a course needs a different configuration within the program, it can be adjusted.*

This document covers the available settings for Blackboard activities and gradebook across all primary programs (**A&S**, **PBSN (RN-BSN)**, **TDAC**, **MSN**, and **MED CAN**). 

---

> [!IMPORTANT]
> **SafeAssign** must be turned on for all assessments/tests manually in the master shell for each one — it is **not** a global feature.

> [!IMPORTANT]
> **PBSN ONLY:** All ATI graded activities in the gradebook must be set to **percentage at 100 points**. Only **NR425** uses a different point distribution.

> [!IMPORTANT]
> **MSN & MED CAN ONLY:** 
> - **Private messaging** should be hidden/removed.
> - **Assessment results settings** are not to be enabled for tests.

> [!IMPORTANT]
> **MSN ONLY:** 
> - The **Gradebook calculation type** should be set to "weighted", and the overall grade should be displayed as a percentage.
> - When a Monday is mentioned (e.g., class on Monday, May 4th), the corresponding module's assignment is due the following Monday (e.g., May 11th).
